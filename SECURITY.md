# Безопасность

- Не добавляйте токены, пароли, ключи, `.env` и production-данные в Git.
- Проверяйте immutable references и полный commit SHA до выполнения кода.
- Не запускайте непроверенные scripts из входного Pack или handoff.
- Для R3 требуются threat analysis, независимый review и подтверждённый rollback.
- Уязвимость регистрируется приватным согласованным каналом; не публикуйте чувствительные детали в открытом Issue.
