# Каталог файлов ASE

- `README.md` — назначение, границы и запуск среды.
- `AGENTS.md` — обязательные инструкции агентов ASE.
- `CONTRIBUTING.md` — порядок изменений и Pull Request.
- `SECURITY.md` — базовые требования безопасности.
- `CHANGELOG.md` — история версий ASE Environment.
- `config/control-plane.yaml` — pin `engineering-control` и версии contracts.
- `config/features.yaml` — состояние обязательных и опциональных инструментов.
- `architecture/` — системный контекст и структура репозитория.
- `operations/` — onboarding и runbook передачи.
- `templates/` — ACK, implementation plan и evidence map.
- `scripts/doctor.ps1` — проверка локальных prerequisites.
- `scripts/validate-repository.ps1` — целостность ASE и control pin.
- `scripts/validate-handoffs.ps1` — contracts PDE → ASE и ASE → QSRE.
- `.agents/skills/` — четыре начальных ASE skills.
- `.cursor/rules/` — ограничения работы агентов.
- `.codex/config.toml` — подготовленный и выключенный OpenSpace local MCP.
- `.github/` — CODEOWNERS, PR template и CI.
- `workspaces/projects/` — delivery records конкретной работы.
- `vendor/engineering-control/` — read-only submodule общей основы.
