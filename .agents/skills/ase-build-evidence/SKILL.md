# Сбор evidence

1. Возьмите полный список AC/NFR из принятого handoff.
2. Для каждого requirement укажите test reference, evidence ID, environment и result.
3. Используйте полный implementation commit SHA и immutable URLs.
4. Зафиксируйте execution time, ограничения и остаточные риски.
5. Не считайте один зелёный CI достаточным доказательством всего Outcome.
