# Подключение сотрудника ASE

1. Клонируйте репозиторий с `--recurse-submodules`.
2. Прочитайте `README.md`, `AGENTS.md` и закреплённый contract в `vendor/engineering-control/contracts/`.
3. Выполните doctor и repository validation.
4. Работайте через отдельную ветку и Pull Request.
5. Код изменяйте в продуктовом репозитории; здесь храните только delivery records и immutable references.
6. Не принимайте handoff с блокирующими вопросами или неверным SHA.
