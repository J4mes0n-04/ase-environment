# Проекты ASE

Для каждой передачи создайте:

```text
workspaces/projects/<project-id>/deliveries/<delivery-id>/
  pde-to-ase.json
  ase-ack.md
  implementation-plan.md
  evidence-map.md
  ase-to-qsre.json
```

Все пояснения пишутся на русском языке. JSON keys и contract enum values сохраняются на английском.
